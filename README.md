# Prime Fire Steakhouse

Премиальный стейк-хаус в Таразе в средневековом стиле.

## Сайт

**Готовая ссылка после включения GitHub Pages:**
https://fandex707.github.io/prime-fire-steakhouse/

## Как включить GitHub Pages
1. Откройте https://github.com/FanDex707/prime-fire-steakhouse/settings/pages
2. Source: Deploy from a branch
3. Branch: main / (root)
4. Save

Через 1–2 минуты сайт будет доступен.

## Локально
Откройте `index.html` в браузере.
